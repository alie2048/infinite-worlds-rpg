## 结论与采用方案

修订前的旧表把单宇宙统一设成 930 亿光年，把无限多元、超越神族的同步系统、至高者一起记作 Rank44，确实遗漏了需要核查的结构层次。以下记录已采用的修订方案，同时把原刊事实与跨刊整合假设分开。

正式综合版采用：**普通完整单宇宙 Rank44；无限平行宇宙的一层集合 Rank51；独立无限多元宇宙的一层集合 Rank52；保留生成关系的完整量子分支递归 Rank55；无限个独立完整递归多元宇宙的全能宇宙 Rank56；至高者的整体创造权能采用 Rank56，依据等级 D。** Rank55、Rank56 是本工程的结构映射和跨刊桥接，不是漫画作者写出的序数。

这一方案不是把同一个 multiverse 连续改名来升级。时间线、平行宇宙、完整递归树、独立多元宇宙集合必须分别指定对象。若一个事件仅涉及当前一层平行宇宙，使用 Rank51；不能因为作品背景有更高整体便给该事件 Rank55 或 Rank56。

## 可复算的结构路径

### 1. 单宇宙、时间线与一层多元

令 U 为一个完整物理宇宙。综合版普通模板取 U=ω，落 Rank44。这不是把现实可观测宇宙默认成无限，也不是把某一块有限星空升为无限，而是采用 S2 的作品内明示。

许多漫威语境的 alternate timeline 就是一个分支宇宙。若 T_i 是一条这样的完整时间线，则 T_i 与该分支的 U_i 是同一个被评估对象，不能再写成“一个时间线宇宙内有一个独立无限宇宙集合”。

对无限个彼此不同的完整分支，按项目的有序分组映射：

`M₁ = Σ(i<ω) U_i = ω·ω = ω² → Rank51。`

因此用户提出的“无限单体 × 无限时间线 = ω²”在上述对象定义下成立。错误做法是算完 M₁ 后，又用“这些时间线也叫无限宇宙”再乘一次 ω。

S3 若只采用普通的一层 multiverse 定义，则：

`O₁ = Σ(j<ω) M₁,j = ω²·ω = ω³ → Rank52。`

这里第二个乘法来自编辑明确列出的独立 multiverse 集合，不来自 universe/timeline 同义词。

### 2. 量子分支递归

S1 的证据不止“有无限多个宇宙”，还包括分支继续生出无限分支的无终止递归。要保留这一关系，本工程可以选用下列 D 映射：

`B₀=U；B_(k+1)=B_k·ω。`

当 U=ω 时，`B_k=ω^(k+1)`。第一代分支 Rank51，第二代 Rank52，第九代达到 ω^10 即 Rank53；更深有限代按实际表达式落在相邻标杆之间。

把所有有限深度以及其生成关系作为一个完整对象时：

`B_∞ = sup(k<ω) B_k = ω^ω → Rank55。`

即使只使用 S1 同页的有限宇宙 n，仍有 `sup(k<ω) n·ω^k=ω^ω`。**基础单宇宙有限／无限之争影响低层，不会自动抹掉完整递归构造。**

这个式子有三个必须明示的工程条件：

- 采用的是分支的代际分组与无限深度结构，不能把普通集合的元素重新编号，就宣称物理体量已经被数学证明为 ω^ω。
- 任一瞬间的“一层现存宇宙清单”与整个生成树是不同记录；前者不因为能继续分支便自动拥有后者的全部作用范围。
- 同一分支沿时间演化不能把相同宇宙的每一时刻当新宇宙重复累加。树的节点关系用来保留新分支的构造深度，不重复计算公共历史的能量。

本稿不使用基数等势把上述工程序数压平；也不声称漫画本身已经给出了唯一的良序或数理逻辑公理。这里的 Rank55 明确属于原著构造约束下的 D 映射。

### 3. 全能宇宙

综合版进一步采用：S3 中每个独立 multiverse，使用 S1 所描述的完整分支递归模板，而不是只截取其中第一代分支。则：

`O = Σ(j<ω) B_∞,j = ω^ω·ω = ω^(ω+1) → Rank56。`

这一跨刊模板统一是 **D 桥接 H-OMNI**。原刊明确的是无限多个 multiverse；“每个均按同一个完整量子分支模板展开”是综合采用规则。若不用 H-OMNI，仅保留一层普通多元的定义，S3 本身仍可支持 Rank52，不能退回“只有一个无限集合所以 Rank44”。

词语 Omniverse 在不同故事中有时作为整体存在的泛称，有时具有 S3 这种额外集合层含义。不能看见一个新 Omniverse 就继续乘 ω，也不能因另一次用词较宽泛而抹掉 S3 的明确区别。

### 4. TOAA 与更高层级

TOAA 的整体创造配置采用 Rank56，结构对象就是 O，不是在 O 上凭“至高”再加一个无限。桥接 **H-OAA** 为：将授权书的整体创造者、诸已知现实的最高创作权能与漫画创世呈现，关联到本稿采用的完整漫威 Omniverse。

H-OAA 属于 D：授权书用了 Multiverse，并未逐项展开编辑页的 Omniverse 定义。若只采用书页最窄的 multiverse 对象，TOAA 对应 B_∞，仍是 Rank55；本稿采用的综合版 56 明确公开最后一步，而不伪装成原刊直述。

没有取得“无限个完整 O 又被重复集合，并将该操作无限次迭代”的证据，因此本轮不继续跳 Rank57、Rank58 或 Rank59。更不能把故事中的作者化身、House of Ideas 或“全能”称号直接换成基数、V 或 Rank125。

TOAA 此处是授权书首现标为《Fantastic Four》#511 的创造者，亦与《Immortal Hulk》#50 的至高／至下呈现关联；**不是同名天神组成员 One Above All**。二者不得互相借用战绩。

## 最低状态审计

漫威没有“第一境界初期”这一统一入口。人类、先天异种、受实验强化者、学习魔法者与装备使用者不能共用一个最初修炼档。

可直接执行的修正：新增 `MV-HUMAN-BASE`，**普通未强化、无特殊装备的人类 Rank0**。原 MV-L0 从“街头强化者”这一泛称中拆出，按 S10 精确注明 Walker 与能量警棍。没有训练、强化和装备资料的新角色，不能默认继承 MV-L0；也不能反向把已经获得超人力量的人当普通人。

本轮没有把 11 吨举力直接换成一击楼房结合能：举力是力／负载条件，缺少位移和对象变化时不是能量，更不是整栋现代大楼的一击破坏证明。S10 的破障说明恰恰有装备档位，所以现行入门泛化需要实改，不能只在脚注说“因人而异”。

1. 删除单宇宙各行的统一 930 亿光年“有限实物”身份；采用本稿 U 的行改为结构量，J 字段留空，不给无限焦耳或太阳倍数。

5. 无限行的“阶内系数1”只表示该配置采用一个相应完整对象，不能再解释成 OAA 与其他同档存在战斗力完全相等。
