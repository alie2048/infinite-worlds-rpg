# 漫威漫画616：世界、版本与计算

## 固定不变的单宇宙与有限段

《Silver Surfer》2016系列#7的无限宇宙描述支持既有U=ω／Rank44。单宇宙永恒、无限手套所属宇宙整体权能、单枚宇宙终结机制、一次单宇宙重建等原行保持。特殊有限口袋世界及既有有限事件亦保持，不能因人物另有高位状态而回填旧事件。

S1《What If?》第二卷#35第1页把基础宇宙写成有限，同时明确无限分支递归；与S2的单宇宙模板为跨刊综合关系。完整历史集合的不可数性不依赖单个宇宙内部是有限还是无限。版本冲突继续保留，原图及刊号见[v2证据索引](reference-04.md)。

## 正式结构算法

完整历史M采用ℕ^ℕ，因此κ=|M|=ℶ₁。该完整历史语义已由用户确认，不再使用ω^ω作为完整M的正式值。

| 对象 | 结构计算 | 落位 |
|---|---|---|
| 单个无限宇宙U | ω | Rank44 |
| 一层可数无限完整分支清单 | ω² | Rank51 |
| 一层无限个上述清单 | ω³ | Rank52 |
| 完整量子历史多元M | κ=ℶ₁ | Rank76档 |
| 有限m倍完整M工程锚 | κ·m | Rank76+，保留m |
| 无限个独立完整M组成的全能宇宙O | κ·ω | Rank76+，无限倍M结构 |
| 若再有独立无限聚合层 | κ·ω² | Rank76+；仅为算例，尚非额外已证对象 |

**无限以上也保留结构增殖。** κ进入结构算式时按其初始序数使用；乘号为项目的结构乘法，不能改用基数等势将κ·ω压回κ。真实分组是采用结构的依据，不能靠人为重新编号升档。

总表Rank76为ℵ₁，Rank77为ℶ₂。不假定CH；ℶ₁及上述分组表达式在当前编号中分别记录为Rank76档、Rank76+并保留精确结构。κ·ω<κ·ω²，但两者不因此自动达到ℶ₂。不同整数Rank之间本来就可能容纳许多不同结构，不删除其阶内差别。

S3《New Exiles》#1编辑页提供无限个独立multiverse，采用O=κ·ω。Megaverse旧手册只确认分组概念，未给每组无限数量；本轮不重复插入一层乘ω。若后续原著关系能支持两层独立无限聚合，则整体按κ·ω²重新计算。

## 保留的D桥接与角色范围

- H-HISTORY：S1按全部完整无限历史均作为独立世界纳入解释；用户已确认采用。
- H-OMNI：S3的每个独立multiverse采用同一个完整M模板，因此全O为κ·ω。
- H-OAA：旧官方Glossary的Omniverse创造者职能，关联完整O，TOAA创造配置为κ·ω。其他时期的较窄用词仍记录，不强称全版本一致。
- H-SYSTEM：S6同步终结整个multiverse的计划对象关联完整M，超越神族全系统为κ；全部机制须齐备，计划未成功执行，单成员不继承。
- H-POWER：S6/S7/S9的同源供能、整体塑造和重建关系，支持杜姆／里德完整供能配置采用κ。已发生的Battleworld残片重组与逐个重建历史不改写为已目击的一次全M创造。
- H-BEY：Secret Wars II #9数百万倍关系的多处转引定位，按κ·m采用原版完整力量；m只记数百万，不虚构精确整数。原图未核读，来源状态保留。

Multi-Eternity整体本体关联M；生命法庭以完整多元裁决和干预权能关联M。全O管理的转引继续核查，不能把仅有单宇宙示例当成其完整上限，也不能未经核对直接宣布覆盖全O。

## 计分与版本边界

一次整体创造、改变、重塑、毁灭均计；局部化身或一次局部事件不自动取得完整本体范围。不同结构、强弱系数、权能和限制分别保留，不以相同整数Rank宣称同实力。

更高神级领域的名称、地理上的外部及单纯职务高低，不直接推出新乘数或新的ℶ层级。原版超越者、后续宇宙立方解释、2015神族与2022版本分开。现有锚是已采用能力配置，不是这些人物的全版本上限。

有限段原有模型与数值本轮完全保持：地球固定参照、真实天体结构换算、低于太阳不做等效直径映射等规则不变。无限项不用焦耳、太阳倍数或有限等效直径。
