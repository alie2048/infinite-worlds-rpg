# 海贼王 · 非物质机制附录

这些条目不参与GBE落位，亦不是Rank0。覆盖范围与系统地位不等于同范围物质的破坏、创造或改变。只要目标实为精神、权限、状态或被转向的载荷，就保留对应机制；需另有实际物质作用证据才能建立能量评分。

## PO4 波塞冬·海王类沟通与统御

目标：海王类个体的行动决策／群体调度。覆盖：受可响应海王类及其所在位置、执行动作约束；未取得一次协同行动物质总量。

统御资格本身没有可替代的物质GBE。撤销q=7群体预算；未来如有被调度群体实际一次作用量，应另评估执行者及物质对象，不直接赋给白星。

条件：需可响应且实际到场的海王类；不能将长期海洋灾害累积成一次作用。

来源：[P1 ONE PIECE 官方剧情总索引](https://one-piece.com/story/index.html)。

## PO5 储存的乔伊波伊霸气·机器人释放

目标：目标精神／霸气对抗与变身维持状态。覆盖：官方蛋头回顾所述现场目标；不等于现场所有物质被改写。

官方确认一次释放并产生解除／逼退效果，但这些结果不能单独确定物质GBE。撤销顶层物理端点的转借；存储载荷的来源、消耗与目标抗性可用于游戏机制，不能据此证明机器人或路飞获得相同本体出力。

条件：依赖预先储存载荷和释放条件；一次释放效果不等于可重复常态攻击。

来源：[P7 ONE PIECE 官方蛋头岛剧情](https://one-piece.com/story/egghead/index.html)。
