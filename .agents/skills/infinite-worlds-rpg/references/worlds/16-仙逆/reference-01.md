# 《仙逆》世界与计算：起点、中锚与终点共用曲线 v5

## 采用点及本次改动

- 大天尊一般代表：1.044 × 10⁵² J；Rank11+；7.796亿倍。以双子陨石动作作为D代表，不再先人为扣除一段进度。
- 仙祖、古祖已过八桥代表：4.175 × 10⁵³ J；Rank12+；1.505倍；一成祖力与四尊关系只约束这段。
- 完整踏天：**2.884 × 10⁶⁰ J；Rank14+；11.78倍**。第四步的增长参考此前完整大境，脱离桥境小段的低斜率。

v4的问题不是乘除算错：它把遗骸对拼的条件关系传成整条高段曲线的斜率约束，又把四步终点接在该斜率上；试炼宫与小劫的节点数还额外稀释了增长。本版先固定少数有证据关联的坐标，再在这些坐标间分配普通境界。

**y＝log₁₀U**；y₀＝log₁₀U成人；yₘ＝log₁₀U山；y_d＝log₁₀U陨石。

## 五衰整段：由原著合爆关系解出

原著第一批是数十头，最低碎涅圆满、最高近第三衰，单体自爆超过自身数倍，合爆约第五衰一击。中央N50、b3，四档比例p=(0.4,0.3,0.2,0.1)，属于词义内的D代表。

令a为这一段的共同相邻倍率：`a⁵=Nb(p₀+p₁a+p₂a²+p₃a³)`。解得 **a=4.8584395799**。逐衰U_j=U碎满×a^j，再用共同曲线的反函数取得q。第五衰／碎满为2707倍，不是旧五次二倍的三十二倍。合爆反算残差低于万亿分之一。

这一小段的几何采样来自一条合爆方程；原文没有说明五次增幅完全相同，等比只是信息不足时的最少参数插值。其他大境没有沿用这个倍率。

## 终点先定，再分配准踏天

一成仙祖剑威与四尊对拼，结合八桥身份，中央取 `U八桥=40U大尊`。这里40是带人物与操控条件的D中心，另算10／100；不用它压住大尊之前的主链，也不用它限制完整第四步。

取从凝气三层到大尊的完整主链平均大境对数增量：

**s=(y_d−y₀)/17=3.4196202038**。

第四步是大步转变，中央采用两段普通大境的对数增量，故：

**U踏天=U八桥×10^(2s)=2.884 × 10⁶⁰ J**。

“两段”是统一成长估计的D权重，不是原文有一个焦耳倍率。其作用是给完整第四步留出与既有成长序列相称的跨度，不把准踏天内部缓慢增长误当跨大步规律。权重1／3均单独算入敏感性。

准踏天第j桥（j=1…8）取：`log₁₀(U_j/U大尊)=log₁₀(40)×(j/8)^1.5`。八桥后一段未过九桥用j8.5采样；完整第四步单独使用上式。只用一个有增长的分配函数，不另外拟合九条桥曲线。全部这些值都能在同一y(q)上反求坐标。

## 古族直接接入

一至九星主曲线坐标为q=[2,3.5,5,6又三分之一,7.5,9.5,11.5,12.5,13.5]；七、八、九星依次接空涅、空灵、空玄。四星与问鼎及五六星、第二步修士的同期表现用于校准。五星、六星原来过低的阳实／净满接口改为窥涅初／碎涅初的D一般代表，避免不再核对就保留旧对应。王族、同修与道古传承不当全族标配。

古神、古魔、古妖共同配置系数为1、0.8、0.6，仍是D选择而非原著百分比。二十七星齐全、虚化融合、完全融合且损劫渡尽直接对应空劫初／金尊／天尊；本源破空直接对应普通空涅。不同路线没有另造曲线。

## 物理与反向检查

山体先按圆锥求体积，再用等体积球估算GBE；石林按半径5000米、平均高50米、填充0.1的稀疏圆盘，U=8GM²/(3πR)。当前婴变中期采用值高于该随手动作代表约1427倍；这是插值余量，不声称原著证明了该额外倍率。

陨石尺寸来自丹海9700万里、横海一月与跨洲数月、祖城堪比一洲、半城陨石。中央一里500米，跨洲6个月、两段有效速度和代表洲径均取相同；这些是假设。旅行低／高情景使直径乘0.25／3，U乘该倍率的五次方。原著已明指陨石，计算的是实际物质对象代理，不是把任意空旷空间填成岩球。

八星条件碎星的同尺度真实结构代理高于一般八星约20.93万倍。本篇没有给普通八星牺牲星点的固定爆发倍率，因此这里只保留条件检查，**不能说该倍数已经被原著验证**。普通七星与数十小修真星的关系也不把每颗星体默认为地球。朱雀未实测大星情景没有锁进普通窥涅。

空灵中期至空涅初，原文分身损失九成修为；本曲线U比为6627倍。这说明采用值不是把修为总量线性当GBE；对应非线性指数为3.821331。甲数六大境十倍关系同理保留，不能一边按修为百分比算焦耳、一边在不合预期时删除反例。

所有一般值都属于推估；通过核验的含义是来源对应、公式、采用点和反向检查一致，不是原著提供了139次独立能量测量。

## 完整复算代码

代码只计算当前Markdown模型，不读取或写回旧JSON、生成器。程序中的e记数是数值字面量；正式显示均用乘幂与中文倍数。

```python
from math import pi, log10
G=6.67430e-11
def sphere(m,r): return .6*G*m*m/r
UA=sphere(70,(3*.07/(4*pi))**(1/3))
VM=pi*500**2*300/3
UM=sphere(2700*VM,(3*VM/(4*pi))**(1/3))
RM=1.455e11/2
UD=sphere(2700*4*pi*RM**3/3,RM)
REF=[(1,3.705966999203785e-9),(2,.0005907238864037964),(3,204.77251629323695),(4,3385085789.8504243),(5,338508578985042.4),(6,1.9164966891744122e23),(7,1.7749949345128213e25),(8,3.903852650290378e27),(9,2.49e32),(10,2.2758439477195338e41),(11,1.338843455284754e43),(12,2.774920981488543e53),(13,3.3471086382118832e56),(14,2.4476758885628535e59),(15,2.4476758885628535e89),(16,2.4476758885628535e119)]

def build(mountain=UM,meteor=UD,ancestor=40,step=2,N=50,b=3,p=(.4,.3,.2,.1)):
    ya,ym,yd=map(log10,(UA,mountain,meteor))
    qm=4.12
    slope0=(ym-ya)/qm
    slope1=(yd-ym)/(17-qm)
    reference=(yd-ya)/17
    def y(q):
        return ya+slope0*q if q<=qm else ym+slope1*(q-qm)
    def qi(logu):
        return (logu-ya)/slope0 if logu<=ym else qm+(logu-ym)/slope1
    pos={}
    for n in range(1,16): pos[f'XN{n:03}']=(n-3)*.5/12
    for start,q in [(16,1),(20,2),(24,3),(28,4),(32,5),(36,6),(46,7.5),(50,8.5),(54,9.5),(63,11.5),(67,12.5),(71,13.5),(83,14.5)]:
        for j in range(4):pos[f'XN{start+j:03}']=q+j/6
    for i,q in zip(range(40,46),[6.6,6.7,6.8,6.95,7.05,7.15]):pos[f'XN{i:03}']=q
    # Five successive declines: one original aggregate relation fixes the
    # whole interval. No arbitrary five copies of a chosen multiplier.
    lo,hi=1.,100.
    for _ in range(120):
        a=(lo+hi)/2
        if a**5>N*b*sum(p[j]*a**j for j in range(4)):hi=a
        else:lo=a
    a=(lo+hi)/2
    for j in range(1,6):pos[f'XN{57+j:03}']=qi(y(pos['XN057'])+j*log10(a))
    for j in range(1,9):pos[f'XN{74+j:03}']=14+j*(.5/9)
    # The trial titles belong to the upper part of Kongjie. They have their
    # own evidenced ordering, not ten or nineteen new major realms.
    pos.update({'XN087':15.6,'XN087P':15.8,'XN088':16.,'XN088M':16+1/6,'XN088L':16+1/3,'XN088P':16.5,'XN089':17.})
    z=log10(ancestor)
    # Bridge weights grow toward the end. The final bridge of the original
    # novel is a change of great cultivation step, not more of this sequence.
    for j in range(1,9):pos[f'XN{89+j:03}']=17+z*(j/8)**1.5/slope1
    pos['XN098']=17+z*(8.5/8)**1.5/slope1
    yt=yd+z+step*reference
    pos['XN099']=qi(yt)
    U={k:10**y(q) for k,q in pos.items()}
    tribes=[2,3.5,5.,6+1/3,7.5,9.5,11.5,12.5,13.5]
    for clan,c in [('古神',1),('古妖',.6),('古魔',.8)]:
        for n,q in enumerate(tribes,1):U[f'XNG{clan}{n}']=c*10**y(q)
    uobject=sphere(2700*4*pi*(5e8)**3/3,5e8)
    U.update({'XNGF1':U['XN083'],'XNGF2':U['XN086'],'XNGF3':U['XN087'],
        'XNV01':uobject,'XNV02':10**y((pos['XN084']+pos['XN085'])/2),
        'XNV03':U['XN071'],'XNV04':U['XN063'],'XNV05':U['XN099'],'XNO1':uobject})
    return dict(U=U,pos=pos,slope0=slope0,slope1=slope1,reference=reference,decline=a,y=y,qi=qi,tribes=tribes,UA=UA,UM=mountain,UD=meteor,ancestor=ancestor,step=step)

def classify(u):
    rank,ref=max((r,v) for r,v in REF if v<=u*(1+1e-12))
    return rank,u/ref


m=build()
for key,value in m["U"].items():
    print(key, value, classify(value))
```
