## 计算规则

基准超赛神Σ₀＝ω；相对量N对应等效结构Σ＝ω·N。增强m倍按右乘：Σ′＝(ω·N)·m＝ω·(Nm)。这是本工程的战力—结构评分映射，不是纯数学自动证明原作新出现N个宇宙，也不等同焦耳乘法。

[分级总表](../../ranks.md)区分：ω为Rank44；ω+1、ω+2为Rank45、46；ω·2为Rank47；ω·3为Rank48；ω·10为Rank49；ω·G为Rank50；ω²为Rank51。G是葛立恒数。有限后继、有限重叠加、无限重叠加、指数递归是不同运算，不能以“变强一次”替代。

本作ω·N有限增殖分支的N不超过100万：N＝1用Rank44；N＝2用Rank47；3≤N<10用Rank48；10≤N≤100万用Rank49。超过标杆时加“+”，同时保留ω·N。标杆结构系数比只比较同一ω前项的有限右系数，如ω·50对ω·10为5倍；它不是序数除法。

ω·100、ω·100万虽同属Rank49，结构量依然不同；均未达到ω·G或ω²。有限倍增不反复增加ω的指数，也不能用集合等势把它们全部压回ω。

## 全王与超神龙：三项作用范围

单条时间线内的一个无限宇宙分支为ω；一个完整编号宇宙包含无限条完整时间线和全部平行历史，为ω²。时间线内部的无限时刻不再另计一次宇宙复制；这里第二个ω来自完整历史分支的无限数量。

## 复算函数

```python
from fractions import Fraction

def classify_current(n):
    assert isinstance(n, int) and 1 <= n <= 1000000
    if n == 1:
        rank, base = 44, 1
    elif n == 2:
        rank, base = 47, 2
    elif n < 10:
        rank, base = 48, 3
    else:
        rank, base = 49, 10
    return rank, n > base, Fraction(n, base)

def classify_structure(power, n=1):
    if power == 1:
        return classify_current(n)
    if power == 2:
        assert isinstance(n, int) and 1 <= n <= 1000000
        return 51, n > 1, Fraction(n, 1)
    raise ValueError("Other structures use the full Rank reference table")

assert classify_structure(1, 12)[0] == 49
assert classify_structure(2, 1) == (51, False, Fraction(1, 1))
assert classify_structure(2, 7) == (51, True, Fraction(7, 1))

```
