# 龙珠：最终采用表（无限结构增殖修正版）

无限段现按结构增殖采用Σ＝ω·N：已有强度提升进入结构评分，再按总表落Rank，具体N保留。除明示关系外，N是工程估值，非原著精确宇宙数；详见[增殖公式与明细](reference-02.md)。

共102条记录，其中E1初见动作、E2大猿宫殿动作已退回对象附表，不计作完整人物或形态落位。旧小动作无法封顶整个角色；反过来后期PL函数向5/10/100外推会错误产生大陆档。因此保留有证据的强度信息，取消这两条的角色默认评分资格，不另造一个完整人物焦耳值。

第21届及以后的可比较强招由毁月与P408共享一条logU关系曲线。官网同场全力龟派气功对波支持关联，毁月另为肌肉最大蓄力，二者按一个公共状态进度相邻处理而非强行等号；其后训练与对抗位置也由同一函数生成。原作早期已出现毁月事实，不能为了抹平童年体术到成熟气功的叙事跃迁，把同场强招压回墙板档再给蓄力造二十八数量级增幅。

低段体术动作与成熟气功没有可唯一回算的连续全态数值链，这是明确保留的资料边界。早期动作参照与后来主强招之比不得称为原著固定成长倍率；本表可调用强招采用点不等于每次普攻，也不代表已发生全部对应范围破坏。

成熟气输出的PL到U是公开工程指数函数，适用域为本表P408及更高读数段。50/2/4等作者数值保留在强度轴，经同一函数转U；不得将导出系数与已换算的U重复相乘。

人造人与布欧时期没有新增官方PL；整段关系曲线的采用坐标及端点全部公开。大猿、界王拳、超赛、融合、吸收是不同形式，不能把所有版本角色排成互斥境界。

真正无限档与有限结合能不作平滑过渡。无限依据、漫画第4话资料缺口、Heroes二手资料局限继承原版，不能借此次曲线审计冒称已经补证所有无限归属。

## 2026-09-19 最低阶段复核

本作没有对应“凝气一层”的全员正式修炼入口；H0普通成年地球人仍为Rank0·H1。表中最早故事样本初见悟空已经受过孙悟饭训练，不能当未经训练者第一天的进步，也不能把第21届强招E3误作全书初入起点。

[官方对漫画第一话的回顾](https://en.dragon-ball-official.com/news/01_672.html)明确悟空破坏布尔玛汽车；[第一话翼龙资料](https://en.dragon-ball-official.com/news/01_2483.html)确认如意棒击倒翼龙的动作，后者带装备。E1的墙板值仅是原表粗物件参照，汽车质量、受损比例和几何未量出，不能认证成悟空全力精确值；它也不负责决定所有人类初学者的强度。E2是大猿条件动作，两者不与后来的成熟气功函数强行连线。

首境核查结论为“无统一修炼初境，普通人体入口保留，初见已修炼个体单列”，没有另造官方不存在的‘武道一层’或把超级赛亚人叫作第一次修炼。最低阶段复核保留；后期无限段现已执行结构增殖修正。
