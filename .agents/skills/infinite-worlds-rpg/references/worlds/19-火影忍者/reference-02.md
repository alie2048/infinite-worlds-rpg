# 火影忍者 · 非物质机制附录

这些条目不参与GBE落位，亦不是Rank0。覆盖范围与系统地位不等于同范围物质的破坏、创造或改变。只要目标实为精神、权限、状态或被转向的载荷，就保留对应机制；需另有实际物质作用证据才能建立能量评分。

## NO3 无限月读·全球生命目标覆盖

目标：符合条件生命的精神／查克拉状态。覆盖：原作星球范围的生命目标；不换算成全球岩层或地壳物质。

全球幻术覆盖与地壳物质作用对象不同。撤销旧薄壳Rank8代理；无需、也不能用同面积岩层自结合能填补精神作用的焦耳值。神树吸取与目标生存状态分别由机制结算，不倒灌施术者物理出力。

条件：需要对应瞳术、月面投影和施术条件；受原作防护与目标条件约束。
