# 火影忍者：世界、公式与审计

## 已核范围与世界尺度

原漫画结局完整；博人传只引入官方数据库的重粒子模式。故事有行星、月球和辉夜多异空间，但没有本次可核的整个宇宙物质尺寸、质量，也没有无上限整体作用证据。本表不认定无限，不按“大筒木”“六道”字样自动授予星球级。

## 主战斗曲线与绝对不确定性

三处共同校准：q=0 取项目标准墙体；q=8 取木叶动作所启发的直径10 km薄盘；q=12 取终战尾兽/六道大范围作战的直径1000 km薄盘工程情景。后者**不是原著给出的1000 km**，是本表最重要的高端自由参数；本次取得的官方资料不能唯一确定它。q=8仍是动作校准、不是佩恩全部能力上限。q=12选取的是高阶战斗配置，双人月球封印留在对象表，绝不以它硬钉所有六道个体。

共享曲线给定全部常规查克拉、瞳术、尾兽、十尾分支的采用预算。q是原著顺序/对战关系约束后的工程坐标；不是查克拉倍数。八门全部使用同一个门数进度式，死门按明确牺牲性质和六道斑对抗作为共同终端；七门自然落在其下，避免孤立增加上亿倍死门跳点。写轮眼前三勾玉保留同物理值，区别在感知机制，不假造肉体倍率。

## 敏感性

木叶直径5/10/20 km；终战代表直径300/1000/3000 km，分别重新拟合整条曲线。区域厚度取min(D/38,30 km)；密度取2200/2700/3300。任何改动应重算全链，不能只抬高某一角色。月球封印若人工天体直径只有现实月球的一半，同密度结合能只有三十二分之一。膨胀求道玉对象情景不可用于人物默认出力；无限月读已退出GBE表，单列非物质机制附录，全球精神覆盖不再冒用全球地壳结合能。

## 关键关系检查

七门 < 六道斑；夜凯与六道斑同对抗区；仙人模式 < 九尾合作 < 六道模式；完成体须佐 > 普通五影模板；辉夜直接战斗 > 六道大战配置；六道联合封印必须双人。比值源于工程曲线，不称作者给出倍率。

## 覆盖与边界

正式职级、咒印、仙术、九尾暴走/合作、全部八门、写轮眼/须佐、十尾/六道均有完整配置。未把每一种忍术、每一个尾兽和每个个体等同独立修炼阶。以本表跑游戏时先选基础体术/查克拉，再选可拥有的分支；禁止把不同分支数值相乘。

## 共享换算函数

N00—N02采用文末独立校准的早期统一曲线，不进入旧q式。其余保留旧配置且使用q的行共享 log₁₀U = -3.22861547 + 1.82837711q + 0.03358114q²。q 是本工程的关系坐标，**原著未给这些坐标值**。同一分支由同一函数产生，不逐行指定两倍、十倍；跨分支相同 q 表示相同游戏物理作用预算，不能推出能力相同。明确的物质对象另用完整公式；非物质机制不生成GBE。

对象模型：均匀岩球 U=3GM²/(5R)，M=4πρR³/3；区域薄盘 U=8GM²/(3πR)，M=πR²hρ；薄球壳 U=GM²/(2R)。岩石默认密度2700 kg/m³。仅计对象自结合能，不把挖掘、动能、温度、离开母星所需能量混进该标尺。地球固定沿用项目 Rank9 标杆，不重定义。

## 数值与语义核验

全部有限值逐行重算 Rank/xk，来源ID完整，人体Rank0单独校验；无Infinity/NaN。各条标记单调的实际成长链都自动检查。行政等级、侧重不同的形态、合击与本体不强行单调；这一点不能掩盖本轮发现的一般状态与旧强作用配置混用，N03衔接尚未核定。程序核验不能证明原著给出了工程尺寸，亦不能证明未知全力上限。
