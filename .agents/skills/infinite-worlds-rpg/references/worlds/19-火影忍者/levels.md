# 火影忍者 · 完整等级与强度分支采用表

原漫画1—700话为主；仅末节重粒子模式采用博人传官方资料。不是所有忍者都有同一套变身。六道、大筒木、影与“超影”均不当作统一可修炼的官方大境界。

组织/行政等级只提供带配置条件的模板。role=category 不构成修炼链；object 不可作为人物本体默认值。C/D 表示原著关系加工程估计，所选尺寸、进度坐标及其桥接均公开。精神覆盖、统御、世界基石、事件拒绝与门户处理载荷等没有物质作用量的机制另列附录，**不设GBE、Rank或阶内倍数**。

**不可把同表相邻行理解为境界连续升级。下列每节单独比较。U 是作用对象自引力结合能等效，不是爆炸热量；低于太阳不输出光年直径。**
