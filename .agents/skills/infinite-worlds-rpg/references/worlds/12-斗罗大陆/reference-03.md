# 斗罗大陆 世界与计算

范围：第一至第四部、神界传说/唐门英雄传相关边界；不接入动画、游戏数值或第五部异界修炼体系。

2026-09-19一般状态修订：魂士正式1—10级统一H(n)＝1＋(n−1)/3，H是D人体参数、不换焦耳。D01采用魂师普通最低阶段一砖D，D01-E已合入；旧105倍熟练代表退为历史，不再有双套H或同境配置曲线。D02以上、世界结构与神级软端保留，JSON未同步。

斗罗星为行星，但本轮没有找到足以确定其半径、质量的原著数字；不把行星一词直接落Rank9。神界、大神圈有内部空间与外部体积区别。大神圈外部可比恒星并不足以证明内部为一个现实星系；远距离神识不算物质作用。

D02以上保留旧M曲线：从历史初阶石块截距到封号代表软控制点（92.5级，由95—99平均log斜率延拓），采用log U插值与统一曲率1.25。95—99主链来自初代20%、20%、30%、40%的魂力量，再以p=1映射为评分，p并非原著。第二部翻倍段独立，不混乘。第三部99状态用1:2:6关系，共用p。唐舞麟数十海里海水作用校准99上端，但他是特殊状态，水深100米、直径50海里都是公开建模选项。圆盘积分计算，绝不将海面自动填充为球。

G曲线从99准神到神王软太阳点沿六个层次共同插值。源文本的舰炮引爆恒星可能是触发过程，神王处理炮击也有空间性质，不能视作输入太阳结合能的硬证据；因此所有神级绝对值D。太阳端的六数量级下移敏感性必须查看，不能把四位有效数字误当精度。

神之怒各点强度等于神级攻击，不等于其整个一万米爆炸总量等于单神攻击。数千天挖墓、长期修复位面均排除一次作用。

| 世界对象 | 已知边界 | 采用处理 |
|---|---|---|
| 斗罗星 | 行星，有海陆 | 没有实测质量半径，不新增整星硬锚 |
| 初代神界 | 有界域，可扩张 | 无距离，身份不转无限 |
| 大神圈 | 集体创世，外部体积可比恒星 | 太阳对象代理D，非单王能力 |
| 系列宇宙 | 有星系、宇宙规则 | 无全域尺寸与一次整体作用证据，不设置宇宙级境界 |

本作没有经过证明的真无限主项。所有有限值使用现行标尺；Rank10以下不做空间等效直径映射。

旧M曲线截距105倍砖体不再是现行D01，仅用于复查保留的D02以上原值。现行D01为一砖，H与GBE不构造能量倍率。本次不扩大为中高段重拟合。
