# 一拳超人 · 非物质机制附录

这些条目不参与GBE落位，亦不是Rank0。覆盖范围与系统地位不等于同范围物质的破坏、创造或改变。只要目标实为精神、权限、状态或被转向的载荷，就保留对应机制；需另有实际物质作用证据才能建立能量评分。

## OX5 空间转移／转向强作用

目标：既有攻击载荷的传播路径／空间连接。覆盖：宇宙饿狼对抗场景中处理合击的条件行为；原作未给所有门户容量上限。

转向或输送既有载荷不能自动转化成施术者生成或硬抗该载荷的GBE。撤销q=7.6交互能量预算；保留其对已发生合击的处理关系，处理对象可引用OX4，但不复制OX4的分数给门户能力。

条件：按实际援助、空间连接和协同条件；不是无条件无限载荷传输。
