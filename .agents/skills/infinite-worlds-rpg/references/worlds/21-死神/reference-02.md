# 死神 · 非物质机制附录

这些条目不参与GBE落位，亦不是Rank0。覆盖范围与系统地位不等于同范围物质的破坏、创造或改变。只要目标实为精神、权限、状态或被转向的载荷，就保留对应机制；需另有实际物质作用证据才能建立能量评分。

## BO2 灵王／替代灵王·三界基石权限

目标：三界分离与稳定所依赖的系统状态。覆盖：三界世界结构；本轮来源未锁定其全部物质尺寸、质量或一次实际改变量。

维持世界稳定、移除基石造成失稳，都不提供主动一次改写三界全部物质的量。撤销三地球预算，三界总GBE也不据此设为三倍地球。若另取得直接创造、重塑、破坏的物质范围证据，应另建物质作用对象。

条件：需要原作指定的基石承载及替代资格；维持、失稳后果、主动出力分开。

来源：[B1 BLEACH 官方术语页](https://bleach-anime.com/keyword/)；[B11 千年血战动画第29集官方简介](https://bleach-anime.com/en/story/?id=29)。

## BAN5 六天死盾·终极拒绝条件（动画）

目标：受保护对象的状态／事件拒绝。覆盖：按动画具体受保护对象和作用条件；“拒绝世界”措辞不直接证明物质总体改写。

官方术语的牺牲与拒绝机制没有独立给出可计算的物质范围。撤销转借漫画终战q=13.5的防御预算；能够拒绝某事件不当然等于同能量硬抗，更不自动证明无限整体作用。

条件：以自身魂为代价，按原作具体对象和终极拒绝条件使用。

来源：[B1 BLEACH 官方术语页](https://bleach-anime.com/keyword/)。
